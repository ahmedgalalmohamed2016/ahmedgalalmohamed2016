**AI Engineer and senior full-stack engineer.** I build LLM-powered products end to end:
retrieval pipelines, tool-using agents, fine-tuned models, and the TypeScript backends

- **RAG systems:** document ingestion, chunking, embeddings, vector search, and evaluation
- **AI agents:** tool calling, memory, and agent runtimes with Mastra and LangChain
- **LLM fine-tuning:** PyTorch and Hugging Face (Transformers, PEFT/LoRA, Datasets)
- **Full-stack:** Node.js, NestJS, Express, React, and TypeScript, with PostgreSQL, MongoDB, Docker, and AWS Lambda
- **Domain:** fintech and payments
